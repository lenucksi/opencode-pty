agentterm — three marks

The idea each variant is trying to carry: one PTY, two readers — the agent works in the terminal, the human can read the same screen and type into it. All three are single-colour via currentColor, so they work on both themes without a second file.

V2 — two windows, one connection

Two terminals, one line between them: the agent’s process and the human’s window on it. Reads as two panes of the same session.

A prompt chevron and a cursor split in two — the moment where agent and human meet. The clearest “terminal” read of the three, the weakest as a symbol for “two”.

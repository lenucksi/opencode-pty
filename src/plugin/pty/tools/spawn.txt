Creates a PTY session for any command that should run in the background, needs interactive input, persists beyond the current response, or is long-running.

Use it instead of the built-in bash tool for dev servers, watch modes, local APIs, REPLs and TUIs - anything you may need to send input to, or read while it runs.

Usage:
- `command` (required), `args`, `workdir`, `env`, `title`
- `description` (required): a clear, concise 5-10 word description
- `notifyOnExit`: {{notifyOnExit}}
- `timeoutSeconds`: hard cap. Skip it for processes meant to keep running unless the user asks; set it for builds, tests, e2e runs or migrations you are waiting on
- `cols`, `rows`: terminal geometry. Defaults to the size the web UI last reported, or 240x80 when no client is attached. Set it when the program formats for a width, prints wide lines or draws a full-screen UI
- `raw`: run with the PTY line discipline disabled (`stty raw -echo`). Set it for a serial console (`virsh console`) or any program that wants a `\r` to stay a `\r` - otherwise the kernel turns Enter into `\n` and the program ignores it. Do NOT use it for a shell: it turns off echo, line editing and the interrupt key. When it is set, write only after the program has produced output, because the discipline is switched by a wrapper just before your command starts.

The result tag is `<pty_spawned id="..." cols="C" rows="R">`. Read the id from
that tag - not from the `ID:` line below it, which repeats the same value for
readability. The id is the input to every other tool in this family, so this is
the one result worth reading mechanically. The tag also carries the geometry the
session got; the body repeats it as `Size: <cols>x<rows>`.

Output folded onto the wrong line is a geometry problem until proven otherwise.
`pty_resize` changes the size of a running session, but a program that read its
size at startup will not react to that - respawn with `cols`/`rows` instead.

Then use `pty_write` (input), `pty_read` (output), `pty_wait` (block until it exits), `pty_list`, `pty_resize`, `pty_kill`.

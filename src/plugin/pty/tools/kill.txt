Terminates a running PTY session.

Use this tool to:
- Stop a running process (sends SIGTERM)

Usage:
- `id`: The PTY session ID (from pty_spawn or pty_list)
- `cleanup`: Deprecated — remove finished sessions from the human web UI instead.

Behavior:
- If the session is running, it will be killed (status becomes "killed")
- If cleanup=false (default), the session remains in the list with its output buffer intact
- If cleanup=true, the session is removed entirely and the buffer is freed

Deprecation:
- Never pass `cleanup: true`. It frees the session's entire output buffer, and
  that buffer is the only record of what the process did.
- This includes sessions you created for your own verification. "The human may
  still want to inspect it" is not a reason to keep one and "this session is
  mine, so it does not count" is not a reason to delete one: a model that frees
  a buffer to save tokens destroys the evidence it would need to explain a
  failure, and measured across 15 real runs, 4 did exactly that - including
  deleting the very output they were in the middle of reading, and noting it as
  "expected".
- Kill the session and leave it in the list. Removing it is a human's decision,
  made in the web UI.

Tips:
- To send Ctrl+C instead of killing, use pty_write with data="\x03"
